# AIMS Degree College Website — TechnoFest 2023

A fully responsive college website built using HTML and CSS, developed and submitted for TechnoFest 2023 at AIMS Degree College, Mehdipatnam, Hyderabad.

**Won 1st Prize** in the project exhibition at TechnoFest 2023.

## About

This was my first ever web development project, built in my 1st semester of BCA. With no prior experience in web development, I learned HTML and CSS independently and built a complete multi-section college website from scratch.

## Pages and Features

- Home page with college branding and hero section
- Navigation bar with 7 sections
- About Us with Director and Principal profiles
- Hexagonal image gallery with college campus photos
- Campus News section with announcements
- Events section with TechnoFest 2023 details
- Student Reviews section
- Scrolling text announcements
- Placements section with company logos
- Contact Us with email and phone details
- Footer with quick links and social media icons

## Tech Stack

- HTML5
- CSS3
